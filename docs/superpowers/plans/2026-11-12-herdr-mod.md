# Herdr mod → NemoNotch 提醒 Implementation Plan

> **For agentic workers:** 本仓恒选主对话 executing-plans 逐任务实现(AGENTS.md「任务入口分流」)。Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Herdr 里 agent 跑完/卡住时经 `/v1/toast` 推绿/蓝卡到 NemoNotch,点卡聚焦 Herdr 对应 agent,处理后自动撤卡;Herdr 侧栏 Spaces 行显示「● NemoNotch」。

**Architecture:** NemoNotch 侧给外部 Toast 协议加四个 additive 字段(`tone`/`herdrTerminal`/`action`/`expiresAt`,schema 仍 1),新增 `HerdrJumper` 执行写死的 `Herdr do agent.focus`;Herdr 侧是仓库内 `integrations/herdr-mod/` 的 gpui-kit JS mod,以常驻无边框浮窗为宿主,由 `scripts/install-herdr-mod.sh` 安装。

**Tech Stack:** Swift 6 / Swift Testing;Herdr 0.1.15 mod(gpui-kit JS,`herdr` 模块);POSIX sh;node 内置 test runner(仅边沿纯函数)。

**Spec:** `docs/superpowers/specs/2026-11-12-herdr-mod-design.md`

## Global Constraints

- schema 仍为 `1`;未知字段忽略;所有新字段可选,缺省行为与现状逐字一致。
- `ExternalCardService` 零语义翻译:`tone` 只改环色,**不**向卡面注入任何文字(`kind.verb` 不得出现在外部卡上)。
- 外部卡**不**触发全屏辉光,只受 `externalToastEnabled` 门禁(带 tone 也一样)。
- `herdrTerminal` 校验:`^([A-Za-z0-9._-]{1,64}/)?[A-Za-z0-9]{1,32}$` 且首字符非 `-`;Herdr 可执行文件经 bundle id `dev.herdr.app` 定位为 `Contents/MacOS/Herdr`,`Process` 参数数组执行 `do agent.focus --terminal <addr>`,不过 shell,超时 3s。
- `herdrTerminal` 与 `jumpURL` 并存时 `herdrTerminal` 赢(`jumpURL` 丢弃);失败回落 `AppActivator.openApp(bundleId: "dev.herdr.app")`。
- `expiresAt`:Unix 秒(数字)或 `"infinity"`;`"infinity"` 必须带 `key`;时间戳为绝对截止,悬停/等待堆/refill 都不顺延。
- mod 浮窗:`kind:"window"`,`key:"nemonotch"`,`keep:true`,`frame:"none"`,`at:{x:66,y:52}`,高 20;只显示圆点 + `NemoNotch`。
- mod 卡面:`app:"Herdr"`,`key:<address>`,title `<space_name> / <tab_name>`(≤120),body `<跑完了|等你回应> · <app> · <title>`(app 为 null 省略该段,≤280),`jumpBundleId:"dev.herdr.app"`;done→`tone:"done"`;blocked→`tone:"approve"`,`expiresAt:"infinity"`。
- 安装卸载顺序:卸载先 `mod.open`(切换关闭)再删文件夹;安装只在 `status.overlays` 不含 `nemonotch` 时 `mod.open`。

## Review Focus

1. **close 撞上等待堆里的卡**——第 5 张以后的蓝卡被挤进等待堆,用户在 Herdr 里答完后 close 必须把它从堆里也删掉,否则它会在别的卡消失时「复活」。→ Task 3 测试 `closeRemovesWaitingCard`。
2. **同 key 由 blocked(infinity)转 done(默认 5 分钟)**——卡必须从常驻变回会到期,不能继承 `sticky`。→ Task 2 测试 `refreshReplacesStickiness`。
3. **悬停后离开不顺延时间戳卡**——`resume` 只给缺省卡重计满。→ Task 2 测试 `resumeKeepsFixedDeadline`。
4. **mod 热重载/重启时不补发旧状态**——首次 render 只种基线,但要撤掉已不在 done/blocked 的残留 key。→ Task 5 node 测试 `firstRunClosesStaleOnly`。
5. **Herdr 不在运行时点卡**——`agent.focus` 失败必须回落打开 Herdr,不能无反应。→ Task 4 手动验证步骤 + `HerdrJumperTests.planFallsBackWhenExitNonZero`。
