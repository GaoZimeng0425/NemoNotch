# CLAUDE.md 重构设计

## 目标

重新组织 CLAUDE.md，解决矛盾冲突、冗余重复和结构混乱问题，使其更清晰易维护。

## 发现的问题

### 矛盾冲突
1. **Git Flow 规则与实际偏好** — 文档要求严格 Git Flow，memory 记录了灵活模式。用户确认要保持严格模式，已更新 memory。

### 冗余重复
2. **架构图 + 文字双重描述** — mermaid 图和"技术架构"文字描述内容完全重叠
3. **两个参考项目表** — "代码借鉴来源"和"参考项目指南"信息高度重叠
4. **参考项目路径声明重复** — 出现两次

### 结构问题
5. **"架构总览"膨胀** — 222 行，混合架构图、陷阱、参考表
6. **陷阱信息错放** — Info.plist 和媒体获取是调试陷阱，不是架构
7. **日志覆盖要求位置不当** — 是开发约定，不是日志系统技术描述

## 重构方案

单文件重组为 6 个章节：

1. **项目概述** — 简介、技术栈、项目结构（不变）
2. **架构** — 只保留 mermaid 图 + Badge 优先级，删除文字冗余
3. **调试陷阱** — 新章节：Info.plist + 媒体信息获取
4. **开发约定** — 合并日志规范、Git Flow（严格）、编码规则、协议设计
5. **参考项目** — 两个表合并为一个统一表
6. **打包发布** — 不变

## 具体变更

### 删除
- "技术架构"子章节（Service 层 / AI 多提供商 / Notch UI / Tab 层 / 核心数据流）
- "代码借鉴来源"独立表
- 重复的路径声明

- Info.plist → 调试陷阱
- 媒体信息获取 → 调试陷阱
- 日志覆盖要求 → 开发约定
- Git Flow → 开发约定
- 协议设计 → 开发约定

### 合并

### 修正
