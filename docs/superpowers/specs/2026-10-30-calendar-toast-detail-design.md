# 日历 toast 卡片:内容 + 点击打开链接(短设计)

日期:2026-10-30 · 状态:用户已批准

- **意图**:日历到期卡片只有标题、点击只关卡;用户希望卡片有内容,事件带会议/链接时可点。
- **内容**:第 1 行标题(不变);第 2 行「HH:mm–HH:mm · 地点」(无地点只有时间);第 3 行仅在事件有链接时出现——Meet/Zoom/Teams 显示平台名,其他链接显示域名(去 `www.`)。链接复用 `CalendarEvent.meetingURL`(URL 字段 + 地点 + 备注里的链接,会议平台优先)。
- **点击**:有链接 → 打开链接并关卡;无链接 → 只关卡;× 只关。
- **快照**:链接在到期生成卡片时记下(同 AI 卡 `CompletionJump`),卡挂 5 分钟期间日历刷新不影响点击。
- **非目标**:无链接时不打开日历 app。
- **方案**:复用 `CompletionJump.tabLink` 承载链接(`AppActivator.activate` 已按 URL 打开),点击决策零改动;卡片文案走新纯类型 `CalendarCard`(单测)。备选是新增 `.openURL` 点击分支——多一套等价路径,不取。
